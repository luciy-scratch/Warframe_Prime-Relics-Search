# Warframe_Prime-Relics-Search
任意のPrimeアイテム(Voidレリックが存在するフレーム/武器に限る)について、抽選可能性のあるレリックを"パーツ・設計図"と"抽選確率"で分類してテーブル形式で表示します。

---

## データリソース
DEが公開しているドロップテーブル[^1]…を解析してjson形式のデータで公開している **Warframe Drop Data**[^2] さんを利用しています。
サイトへのアクセス時にアクセスユーザー側でjsonデータをダウンロードしてデータリソースとして利用しています。

> [!CAUTION]
> 短時間に何回もページやデータの更新を行うとデータリソース側に負担を掛けることになりますので控えてください。<br>基本的にデータリソースの更新は上流となるドロップテーブルの更新後に行われますが、更新の反映には数時間のラグを伴います。<br><br>アップデート直後のデータに関しては手動でモックデータに読み込む場合があります。<br>モックデータを速報的に更新した場合はコミット時のコメントに記載します。

## 機能

### 検索機能

- 検索欄の入力値、またはドロップダウンボックスの選択値でレリックのドロップアイテムを部分一致検索し、該当するアイテムを含むレリック名を構成パーツと抽選レアリティで分けて表示する機能
- 部分一致検索の結果から現時点ドロップしない（Vault済みの）レリックを除外して表示させる機能（検索欄ごとの`現行ドロップのみ`スイッチ、またはページ上部の`全パネル切替`スイッチからON/OFFの切り替えが可能）

### ユーザビリティ機能

- 有効なパラメータを指定してアクセスした際に、適用されているパラメータの内容とそれらパラメータを削除して再表示する`パラメータを消す`ボタンを表示する機能
- 各検索欄に値が入力されたとき、ワンクリックで値を削除するボタンを配置する機能
- ドロップテーブルをデータリソース側から再取得する機能（F5で再読み込みする負担を削減、ページ上部の`データ更新`ボタンから実行）

### 出力機能

- 各検索欄の検索結果をPNG画像で出力する機能（値が入力されている検索欄の下部`PNG保存`ボタンから実行）

### 内部機能

- ドロップテーブルをデータリソース側から取得し、解析する機能
- 検索結果のレリック名からティア毎に色分けして表示する機能
- 有効なパラメータを受けた際にそのパラメータを適用してページを表示する機能
